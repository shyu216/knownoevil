大语言模型现状(2026.9)

Dale2026/9/19大约 9 分钟

这是截至2026年9月的全球大模型参赛者地图。距离 5 月那版只过了四个月，但格局又换了一张皮——发布节奏已经从"每周多发"演化成"每天都有模型在刷榜"，LLM Stats 统计 Q2+Q3 迄今已有 580+ 个模型发布。上一季埋的钩子几乎全部兑现：Grok 5 如期落地、Kimi K3 带着 2.5 万亿参数杀到、华为昇腾950 超节点量产让 DeepSeek 把价格再砍一刀。中美顶尖模型性能差距已收窄到 1.4%（斯坦福 2026 AI 指数年中更新），"双极并立" 从口号变成了实测事实。

但这四个月真正的新变量不是"谁又强了"，而是 智能体从"能干活"跃迁到了"自己闭环"——主流模型不再只输出文本/代码，而是原生拥有浏览器、终端、工具调用、长时记忆甚至"自托管子智能体"的完整栈。与此同时，端侧/边缘模型 借着手机 NPU 和苹果/高通的本地推理框架第一次挤进了第一梯队讨论。

🌍 全球第一梯队：美国阵营的「全栈智能体」

美国头部 labs 的新主旋律是 「谁的智能体能自己把活干完，不用人盯着」。闭源高性能仍是底色，但竞争焦点已从单次推理质量转移到 端到端任务成功率（terminal-bench / OSWorld / agentic-coding 全品类基准）。推理架构早已是默认，现在比的是谁能把工具、记忆、沙箱、多智能体编排一次性打包好。

参赛者代表模型 (2026.09)核心风格与打法
OpenAIGPT-6（8月12日 DevDay 发布），GPT-6-mini（9月成为 ChatGPT 默认）「Agent 操作系统化」。GPT-6 原生内置 "Computer-Use" 沙箱，能在隔离环境里自己开浏览器、跑命令行、调 API 完成多小时长任务，terminal-bench 2.0 冲到 91.3%。配套的 Codex Teams 让一个主智能体派发子任务给多个 worker，开发者生态闭环彻底成型。GPT-5.5 系列转为低价档。
AnthropicClaude Opus 5（7月28日），Claude Sonnet 5「编程与长任务双冠」。Opus 5 在 SWE-bench Verified 上拿下 91.8%，首次突破 90% 大关；在 OSWorld 多步 GUI 自动化基准上以 62.4% 领先全行业。Claude Code 满意度在 JetBrains 调研中升至 94%，NPS 61 刷新品类纪录。Claude Mythos（原网络安全定向模型）已开放公测，主攻红队/漏洞挖掘场景。
GoogleGemini 4 Pro，Gemini 4 Flash（8月），Veo 4「科学推理 + 视频双霸主」。Gemini 4 Pro 在 GPQA Diamond 达到 96.1%，并把 200 万 token 上下文做成默认配置。原生多模态推理进一步统一：文本/图像/音频/视频/代码一个栈进出。Veo 4 把视频生成 Elo 重新拉回美国阵营第一，结束了 5 月时中国包揽前五的局面——但中国仍有三席紧随。
xAIGrok 5（6万亿参数，7月全面放开 API）「超大规模 + 极致低价」。如期兑现 Q2-Q3 预期，1.5M 上下文、原生视频/音频输入，定价 $0.80/M 输入 token，比 Claude Opus 低约一个数量级。Intelligence Index 得分 58，登顶全球。SpaceX 收购完成后的协同开始显现：Grok 直接接入星链边缘节点做低延迟推理，并内嵌进特斯拉车机与 Optimus 机器人栈。Grok 5.5（推理专精）预计年底。
MetaLlama 5 Scout & Maverick（8月）「开源生态守门员」。Scout（轻量）和 Maverick（旗舰）两款齐发，Maverick 在消费级 8×H100 即可微调，社区衍生模型突破 35 万个。与 Mistral 4 一起，继续扛"开源可替代闭源"大旗，并在 端侧蒸馏 上发力——Llama 5 Mobile 可在手机本地跑 70B 量化版。
MistralMistral Medium 4（Apache 2.0 许可）「欧洲开源的硬气 2.0」。150B 稠密模型，SWE-bench Verified 82.3%，512K 上下文，Apache 协议全开放（比 MIT 更宽松）。Vibe 2 远程智能体 支持长时异步工程，集成 GitHub/Linear/Jira/Sentry/Slack，成为 Claude Code 之外最完整的工程体验替代。

🇨🇳 中国阵营：「价格地板」再破 + 「端侧觉醒」

中国阵营这四个月干了两件事：一是把 API 价格继续砸穿地板（DeepSeek V5 在昇腾950 加持下，缓存命中价低至 ¥0.008/M token）；二是 端侧/边缘模型 第一次成为主线叙事——手机厂商和芯片厂把大模型塞进设备本地，绕开了云 API 的成本与隐私天花板。视频生成仍是中国的招牌，全球视频 Elo 前五里中国占三席（Veo 4 重回第一，但可灵/Kimi-Video/Seedance 紧跟）。

参赛者代表模型 (2026.09)核心风格与打法
深度求索 (DeepSeek)DeepSeek V5（昇腾950 量产版），DeepSeek-V4-Terminus「开源颠覆 + 垂直算力」。V5 在华为昇腾950 超节点上全量训练，激活参数 21B，日常编程完成度 92%，价格是 GPT-6 的 1/80。独创的 DSA-2（分层稀疏注意力） 把 1M 上下文推理成本再降 40%。"模型权重+框架+部署工具"全栈开源策略逼得全球定价继续下探。
阿里 (Qwen)Qwen4-Plus，Qwen4-Thinking，Qwen4-Omni「全模态生态狂奔 2.0」。Qwen4 一口气把推理/语音/全模态/视觉/端侧统一到一套架构，Hugging Face 衍生模型数量仍是全球第一（超 40 万）。新增 Qwen4-Edge 端侧系列，1.8B/4B/7B 三档可在手机/车机本地跑，中文与多语言优化继续领跑。
智谱 (Zhipu)GLM-6（8月），GLM-5.5V（多模态）「低幻觉 + 强 Agent」。GLM-6 幻觉率压到 0.7%（一线最低），Agentic Coding 能力达 Claude Opus 5 的 96.8%，国内编程一线。配套 Zhipu Agent OS 提供长时任务编排与自托管子智能体，定价 $0.06/M，主打"闭源体验、开源价格"。
月之暗面 (Moonshot)Kimi K3（2.5万亿参数，8月发布）「国产军备竞赛兑现」。如期兑现三季度预期，2.5T 参数的 MoE 旗舰，长文本与低价组合拳升级到新高度。在国产编程排名中与 GLM-6 并列第一梯队，并在 长程 Agent 任务（多小时自主研究/编码）上实测口碑第一。Kimi-Video 进入全球视频 Elo 前五。
MiniMaxMiniMax M3，Music-2「Agent 场景极致效率」。M3 延续 12B 激活轻量路线，仍是 Agent 性价比最优解之一；新增 端侧 M3-Tiny（3B 量化本地跑）。Music-2 音乐生成质量追平 Suno，依托国内音乐生态快速落地。
字节跳动Seedream 5（图像），Seedance 3（视频），Seed-OSS-2「图像视频原生 + 端侧补位」。Seedream 5 与 Seedance 3 在全球图像/视频 Elo 榜稳居前列；Seed-OSS-2 开源推理模型补全社区短板，并把端侧蒸馏版打进抖音/TikTok 客户端做实时特效。
百度 (Baidu)文心 X2（推理升级版）「中文语料 + 自研算力 2.0」。X2 推理专项增强，结合百度中文知识图谱与文心一格生态，百科问答准确性国内领先。昆仑芯 3 代集群扩容到 5 万卡，软硬协同路线不变，并上线端侧文心 Mini 系列。
小米 (Xiaomi)MiMo-V3-Pro（1.8T MoE，Apache 2.0）「手机厂商的二次冲击」。参数近 2 万亿，激活仅 60B，Apache 协议全开放。依托澎湃 OS 把 MiMo-V3 直接烧进手机/车机本地推理，是本季端侧叙事的最大推手，证明手机厂不只是"接入"，而是"自研底座"。

🎯 对你有用的观察

  1. 如果你要做 AI 编程/Agent：首选 Claude Opus 5（SWE-bench 91.8% 封顶），全栈长任务选 GPT-6（Computer-Use 原生闭环），国内预算有限选 GLM-6 或 DeepSeek V5，成本差一个数量级。
  2. 如果你要本地/端侧部署：本季最大变化——端侧模型第一次能打。优先考虑 Llama 5 Mobile、Qwen4-Edge、MiMo-V3（小米）或 MiniMax M3-Tiny，手机/车机本地推理已成现实，绕开云端成本与隐私天花板。
  3. 如果你要做视频产品：格局变了——Google Veo 4 重回第一，但中国 Seedance 3 / Kimi-Video / 可灵 紧追，三席在前五。基础设施可中美双线备选，别再只押一边。
  4. 如果你在意科学/学术推理：Gemini 4 Pro 以 GPQA Diamond 96.1% 独占鳌头，依旧没有对手；长文本/研究型 Agent 则看 Kimi K3。
  5. 趋势观察：2026 年的竞争已完成四次跃迁——从「谁更强」→「谁能干活」（Agent）→「谁更便宜还能干活」→ 现在的 「谁的智能体能自己闭环，且能跑在端侧」。中美顶尖模型差距只剩 1.4%，双极并立已成定局；下一阶段的主战场不是"更聪明"，而是 垂直整合（算力+模型+设备） 和 Agent 任务闭环率。同时留意：欧美中三地 AI 监管（EU AI Act 落地、美国行政令细化、中国生成式 AI 标识新规）正在把"可审计/可溯源"变成模型上架的硬门槛。
