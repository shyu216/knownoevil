大语言模型现状(2026.5)

Dale2026/5/26大约 7 分钟

这是截至2026年5月的全球大模型参赛者地图。格局比2月又乱了一圈——发布节奏从"每月一发"变成了"每周多发"，LLM Stats 统计 Q1 2026 单季度就有 255 个模型发布，折合每天三款。中美顶尖模型性能差距已压缩到 2.7%（斯坦福 2026 AI 指数报告），真正进入多极竞争时代。

🌍 全球第一梯队：美国阵营的「智能体军备竞赛」

美国头部 labs 的新主旋律是 「谁的智能体更能干活」，闭源高性能依然是底色，但发布节奏快到每家都在打补丁式迭代。同时出现了一个新变量：推理能力已从"可选模式"变成默认架构，所有主流模型都内置了多步推理。

参赛者代表模型 (2026.05)核心风格与打法
OpenAIGPT-5.5（4月23日发布），GPT-5.5 Instant（5月5日成为 ChatGPT 默认）「幻觉大幅下降」。与 GPT-5.4 相比幻觉率降低 60%，Terminal-Bench 2.0 达到 82.7%，是当前 Agent 终端工作流的最强基准。GPT-5.5 Pro 主打并行推理，配合 Codex 平台形成开发者生态闭环。
AnthropicClaude Opus 4.7（4月16日发布），Claude Sonnet 4.6「编程独步天下」。Opus 4.7 在 SWE-bench Verified 上拿下 87.6%，在 Cursor 内部 93 任务基准中，解决了 Opus 4.6 和 Sonnet 4.6 都拿不下的 4 道题。Claude Code 在 JetBrains 开发者调研中以 91% 满意度领跑 AI 编程工具，NPS 54 分是该品类最高。另有定向安全模型 Claude Mythos（限量内测，主攻网络安全场景）。
GoogleGemini 3.1 Pro，Gemini 3.1 Flash-Lite（5月8日），Gemini 3.5 Flash「科学推理与视频霸主」。Gemini 3.1 Pro 在 GPQA Diamond（博士级科学问答）上达到 94.3%，是当前科学推理第一。3.1 Ultra 支持 200 万 token 上下文。Gemini 3.5 Flash 以 1656 Elo 的 GDPval-AA 写作评分超越 Claude Sonnet 4.6，而 Sora 2 于 3 月关停后，Veo 3.1 成为现存最强视频生成模型。
xAIGrok 4.3（4月17日 Beta，5月全面放开 API）「性价比闯入一线」。1M 上下文窗口，内置推理，原生视频输入，定价仅 $1.25/M 输入 token，约为 Claude Opus 的十分之一。Intelligence Index 得分 53，跻身全球前列。值得关注：SpaceX 已完成收购 xAI，Grok 正融入更大的企业生态。Grok 5（传闻 6 万亿参数）预计 Q2-Q3 发布。
MetaLlama 4 Scout & Maverick（4月5日）「开源生态搅局者」。Scout（轻量）和 Maverick（旗舰）两款同时发布，消费级显卡可运行轻量版，社区衍生模型已超 10 万个。与 Mistral 3 一起，成为"开源可替代闭源"叙事的核心代言。
MistralMistral Medium 3.5（MIT 许可）「欧洲开源的硬气」。128B 稠密模型，SWE-bench Verified 77.6%，256K 上下文，MIT 协议全开放。配套 Vibe 远程智能体支持异步云端编程，集成 GitHub、Linear、Jira、Sentry，对标 Claude Code 的工程体验。

🇨🇳 中国阵营：「价格地板」与「视频称王」

中国阵营这一季最显著的两件事：一是把 API 价格继续往地板砸（DeepSeek V4-Flash 缓存命中低至 ¥0.02/M token）；二是视频生成全面超越美国，全球视频模型 Elo 榜前五中，中国占四席——Sora 2 的倒下是标志性事件。

参赛者代表模型 (2026.05)核心风格与打法
深度求索 (DeepSeek)DeepSeek V4-Pro / V4-Flash，DeepSeek-V3.1-Terminus「开源颠覆持续进化」。V4-Flash 激活参数 13B，日常编程任务完成度达 88%，价格是 GPT-5.5 的 1/36。独创 DSA（稀疏注意力机制），大幅降低长上下文计算量。预告下半年华为昇腾950超节点量产后，Pro 版价格还要大幅下调。
阿里 (Qwen)Qwen3.6-Plus，Qwen3-Max-Thinking，Qwen3-TTS，Qwen3-Omni「全模态生态狂奔」。这一季 Qwen 系列一口气补全了推理、语音、全模态、视觉等全品类。Hugging Face 上 Qwen 衍生模型数量依然全球最多，是开发者"魔改"的首选底座。多语言与中文场景优化持续领先国内同行。
智谱 (Zhipu)GLM-5.1（4月7日），GLM-4.7，GLM-4.5V（多模态）「低幻觉的工程选手」。GLM-4.7 在华为昇腾芯片上完成全量训练，幻觉率 1.2%，是目前一线大模型中最低的数字，定价 $0.11/M。GLM-5.1 的 Agentic Coding 能力达到 Claude Opus 4.6 的 94.6%，是国内编程场景一线选手。
月之暗面 (Moonshot)Kimi K2.6，K3（传闻 2.5 万亿参数，三季度预期）「长文本与低价的组合拳」。K2.6 在编程社区实测中依然保持高口碑，在国产大模型编程排名中与 GLM 并列第一梯队。K3 已曝光：参数规模将达 2.5 万亿，预计三季度发布，国产军备竞赛升级。
MiniMaxMiniMax M2.7，Music-1.5「Agent 场景极致效率」。M2.7 延续前代 10B 激活的轻量路线，依然是 Agent 场景性价比最优解之一。Music-1.5 主打音乐生成，配合字节的音乐赛道同台竞争。
字节跳动Seedream 4.5（图像），Seed-OSS（推理开源）「图像与视频原生」。Seedream 4.5 在图生图和文生图上持续迭代，依托抖音/TikTok 生态快速验证。Seed-OSS 开源推理模型面向社区放开，补全字节在开源生态的短板。
百度 (Baidu)文心一言 X1.1（推理升级版）「中文语料+自研算力」。X1.1 针对推理能力做专项增强，结合百度庞大中文知识图谱，百科问答准确性在国内依然领先。昆仑芯集群持续扩容，软硬协同路线没有改变。
小米 (Xiaomi)MiMo-V2.5-Pro（1.02T MoE，MIT 许可）「手机厂商的意外冲击」。参数量超万亿，激活仅 42B，MIT 协议全开放，是本季最意外的开源新玩家。证明了手机厂商也能打入大模型第一梯队。

🎯 对你有用的观察

  1. 如果你要做 AI 编程/Agent：首选 Claude Opus 4.7（最强 SWE-bench），国内预算有限选 GLM-5.1 或 DeepSeek V4-Flash，成本差一个数量级。
  2. 如果你要本地部署：MiMo-V2.5-Pro（小米）是本季最大惊喜，万亿参数 MIT 协议，媲美 Llama 4 的开源生态潜力。Mistral Medium 3.5 同样 MIT 协议，是欧洲替代方案。
  3. 如果你要做视频产品：别再等 Sora 了，它已经关了。基础设施优先考虑 Google Veo 3.1 或国内视频模型，中国模型在这个品类全面领先。
  4. 如果你在意科学/学术推理：Gemini 3.1 Pro 以 GPQA Diamond 94.3% 独占鳌头，没有对手。
  5. 趋势观察：2026年的大模型竞争已经完成三次跃迁——从「谁更强」到「谁能干活」（Agent），再到现在的 「谁更便宜还能干活」（成本+智能体的双重压缩）。同时，中美顶尖模型的性能差距只剩 2.7%，"美国领跑、中国追赶"的叙事正式终结。

数据来源：斯坦福 AI 指数报告 2026、Artificial Analysis Intelligence Index、DataLearner AI 排行榜、LLM Stats、各厂商官方发布（截至 2026 年 5 月 26 日）。大模型发布节奏极快，建议每月核对一次最新版本号。
