Household and Personal Care Products

Dale2026/9/30大约 5 分钟

这篇文章把日化用品相关的英语词汇按清洁、个护、家居、化妆品四大品类整理成对照表，每一项都附上词源、发展和记忆方法。

一、清洁用品

中文英语来源与发展记忆
洗衣液laundry detergentdetergent 源自拉丁语 detergere（擦去、洗净），1600年代进入英语，最初是医学用语“清洁剂”；1930年代起才专指化学洗涤产品 。laundry 来自古法语 lavanderie（洗衣处）。“detergent” = de（away）+ terg（wipe）→ 把污渍“擦掉的东西”。洗衣液就是液体版 detergent。
洗衣粉washing powderwashing powder 最早记录于1860年代 ，是工业时代肥皂粉的延续。直译“洗的粉”，简单粗暴，反而好记。
柔顺剂fabric softenersoftener 由 soften（软化）+ -er（剂）构成，最早出现于1600-1610年代 。fabric softener 是20世纪随合成纤维普及而流行的产品。soften = 使软，-er = 剂 → “使织物变软的东西”。
漂白剂bleachbleach 源自古英语 blǣcan（使变白），与“black”同源但意思相反，日耳曼语系 inherited word 。记住“bleach 和 black 长得像但意思反”——一个把颜色去掉，一个把颜色加上。
洗洁精dish soap / dishwashing liquiddish soap 是传统说法，dishwashing liquid 是20世纪液体洗涤剂工业化的产物。洗碗用的 soap/liquid，按场景记。
消毒液disinfectantdis-（去除）+ infect（感染）+ -ant（剂）→ 去除感染的药剂。拆词记忆：dis + infect + ant。
洁厕灵toilet cleanertoilet 来自法语 toilette（梳洗打扮），后指洗手间；cleaner 是通用后缀。按用途记：擦马桶的 cleaner。
管道疏通剂drain cleanerdrain（排水管）+ cleaner。直译“排水管清洁剂”，功能即名称。

二、个人护理

中文英语来源与发展记忆
洗发水shampoo源自 印地语 cāmpo（按摩、揉搓），18世纪进入英语，最初指印度式头部按摩，后演变为“洗头” 。记住“shampoo 本来是按摩”——从按摩头到洗头，语义缩小了。
护发素conditionercondition（调节）+ -er。20世纪中期随洗护分开的概念流行。“调节头发状态的东西”。
沐浴露body wash / shower gel20世纪后期产品细分化的产物，用 wash（洗）和 gel（凝胶）组合命名。body + wash，功能一目了然。
香皂soap词源有古罗马传说：Mount Sapo 的祭祀油脂与木灰混合，随雨水流入台伯河，形成清洁黏土 。传说记忆法：Sapo 山 → soap。
洗手液hand sanitizer / liquid hand soapsanitizer 来自拉丁 sanitas（健康），19世纪进入英语。sanitizer = 使健康的东西。
牙膏toothpaste更早的说法是 dentifrice，源自拉丁 dentifricium（dens 牙 + fricare 摩擦），即“磨牙的东西” 。toothpaste 是20世纪随软管包装普及的叫法。dentifrice 拆词：dent（牙）+ fric（摩擦）。toothpaste 则更直白。
漱口水mouthwashmouth + wash，19世纪后期出现。直译“洗嘴的水”。
防晒霜sunscreensun + screen（遮挡物）。20世纪中期随防晒意识增强而普及。挡住太阳的 screen。
除臭剂deodorant拉丁 de-（去除）+ odor（气味）+ -ant → 去味剂。de + odor → 去掉气味。
止汗剂antiperspirant拉丁/希腊 anti-（对抗）+ perspirare（出汗）→ 抗出汗剂。anti + perspir（出汗）→ 对抗出汗。

三、家居用品

中文英语来源与发展记忆
纸巾tissue / facial tissuetissue 源自法语 tissu（织物），14世纪进入英语，本义“编织物”；19世纪医学借用指“组织”，20世纪才用于薄纸产品 。记住“tissue 本来是织物”——从布到纸，都是薄薄一层。
卫生纸toilet paper现代卷筒卫生纸由美国人 Joseph Gayetty 于1857年首次商业化销售 。toilet + paper，功能+材质。toilet + paper，简单直接。
厨房纸巾paper towelpaper + towel（毛巾），20世纪随厨房卫生需求增长而普及。纸做的 towel。
湿巾wet wipeswet + wipe（擦），20世纪后期产品。湿的 wipe。
保鲜膜plastic wrap / cling filmcling（紧贴）+ film（薄膜），20世纪中期随塑料工业发展。cling = 紧贴，film = 膜。
锡纸aluminum foilfoil 来自拉丁 folium（叶子），本义“薄片”。铝箔17世纪起用，20世纪普及。foil = 叶状薄片。
拖把mop可能源自拉丁 mappa（布），与 map 同源，15世纪进入英语。mop 和 map 同源——都是“布/纸”。
垃圾桶trash cantrash 源自挪威语 trask（垃圾），19世纪美式英语用法。trash = 垃圾，can = 容器。

四、化妆品

中文英语来源与发展记忆
口红lipsticklip（唇）+ stick（棒），19世纪后期出现，最初是染唇的小棒 。lip + stick → 唇棒。
唇膏lip balmbalm 来自拉丁 balsamum（香膏），本义“镇痛软膏”。balm = 舒缓膏，lip balm = 唇部舒缓膏。
粉底foundation本义“基础、地基”，化妆品借用指“打底”。化妆的“地基”。
遮瑕膏concealerconceal（隐藏）+ -er → 隐藏瑕疵的东西。conceal = 隐藏。
散粉loose powderloose（松散的）+ powder（粉），与 pressed powder（粉饼）相对。loose = 没压实的。
腮红blush本义“脸红”，古英语 blyscan（变红）。blush 就是脸红，腮红让你脸红。
眼影eyeshadoweye + shadow，眼睛的“影子”。眼睛的 shadow。
眼线笔eyelinereye + liner（画线的东西）。眼睛的 liner。
睫毛膏mascara源自西班牙语 máscara（面具），与 mask 同源。mascara 和 mask 同源——给睫毛“戴面具”。
卸妆水makeup removermakeup + remover（去除剂）。去掉 makeup 的东西。
指甲油nail polishpolish 来自拉丁 polire（打磨光亮），指甲的“抛光剂”。指甲的 polish。
香水perfume法语 parfumer 借入，mid-1500s 进入英语 。fume 来自拉丁 fumus（烟）——最初与焚香烟雾有关。per（穿过）+ fume（烟）→ 弥漫的香气。
