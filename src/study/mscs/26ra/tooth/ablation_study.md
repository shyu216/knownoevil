## 2. 环绕视图分析（Ring View Analysis）

### 2.1 几何

环绕视图生成（`01_gen_ring_view.py`）：

```
θ(u) = -45° + u × 270° / 800          (u = 全景列, 0..799)
camera pos = MC + r × [-cos(θ), 0, sin(θ)]
camera look_at(MC)
```

世界角（MC→相机，XZ 平面）：`world_angle = atan2(sin θ, -cos θ) = (180° - θ) % 360`。

关键列映射：

| 列 u | θ | MC→相机角 | 含义 |
|:---:|:---:|:---:|:---|
| 0 | -45° | 225° | 左后 |
| 133 | 0° | 180° | 左 |
| 267 | 45° | 135° | 左前 |
| 400 | 90° | 90° | 前 |
| 533 | 135° | 45° | 右前 |
| 667 | 180° | 0°/360° | 右 |
| 800 | 225° | 315° | 右后 |

全部 5 个环绕视图（h=200/250/300/350/400）共享同一相机轨迹，仅高度不同。

## 6. 环绕 vs 参考 几何一致性

### 6.1 检查 1：最近参考 ≠ 几何最近（按环绕光线）

来自 `08_verify_geom.py`（625 帧）：

| 指标 | 结果 |
|:---|---:|
| 最佳参考 = 环绕光线最近 | **5.4%**（34/625） |
| 最佳参考在 Top-3 | **19.8%** |
| 角度 vs 匹配数 相关性 | r = **-0.22**（极弱） |

原因：环绕视图是固定的全景参考；PV 帧来自移动的 HoloLens 2（微软混合现实头显 / Microsoft MR headset）。两个视角相互独立——环绕的几何方向无法预测 PV 帧的最佳参考。

> **参考代码：** `exp_script/08_verify_geom.py` (625 帧)

### 6.2 检查 2：按相机位置比较 → 一致

修正 `08_viz_single_frame.py` 使用**相机位置**（而非表面质心）后：

> **参考代码：** `exp_script/08_viz_single_frame.py`

```
环绕相机 @108° → 最近参考 = V11(90°) + V36(117°)
PV 最佳参考 = V11(90°) → 一致 = 是
```

## 9. 最终结论（Final Conclusions）

1. **环绕视图**：h=400 + scale=0.64 最佳（90% 成功率）。PnP 位姿不可靠，但匹配质量尚可。
2. **参考视图**：XY_front（90°）+ scale=0.80 匹配最佳。正面优于侧面。
3. **包围盒 → 环绕视图**：无预测能力。干脆固定 view 4（h=400）。
4. **包围盒 → 参考尺度**：弱相关（MAE=0.082）；包围盒越宽 → 尺度越大。
5. **环绕相机位置**能预测最近的参考视图，但 **PV 帧的最佳参考由拍摄角度决定，而非环绕几何。**
6. **整体一致性**：环绕相机位置 ↔ PV 最佳参考 一致（与相机相关）；环绕表面质心 ↔ PV 最佳参考 不一致（与内容相关）。前者成立，后者不成立。

> **参考代码：** 生成器：`demo_script/01_gen_ring_view.py` + `01_gen_guide_view.py`；匹配器：`exp_script/helper_ai.py` → `strategy_ringview_ray()` (L1407)
